Sections

Toggle which content sections appear in the digest. Items that don't match any enabled section are still counted in Summary totals but have no home in the body.

Sentiment thresholds

Boundaries for Positive / Negative buckets. Items with sentiment between these values are neutral (no badge). Global default: +0.2 / −0.2.

Headline LLM pass

Number of top persistent-issues per section that get eager LLM- generated headlines. Higher = more polished-looking digest; more assistant-LLM tokens per digest generation. Cached by content hash, so re-renders are free.

Requires the assistant LLM to be configured (Connections). Without it, rows render with a canonical title fallback.
