How LLM provider selection works

The pipeline uses the OpenAI SDK pointed at the endpoint configured per product (and per-stage: relevance vs classify). The right API key is picked from .env based on the endpoint URL: api.anthropic.com → ANTHROPIC_API_KEY, api.openai.com → OPENAI_API_KEY, googleapis.com → GOOGLE_API_KEY, etc. Local endpoints (Ollama, Foundry Local, vLLM) get a placeholder key the SDK ignores. Override the mapping by adding api_key_env to a routing entry in llm_routing.yaml.
