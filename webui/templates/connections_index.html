Why per-source-type?

Most credentials are global: one Reddit API key, one GitHub PAT. A single .env file holds them; every product that has a Reddit source instance uses the same client. Per-instance secret overrides could be added later (e.g., a per-product GitHub PAT) but V1 keeps things simple — set it once here, all products see it.
