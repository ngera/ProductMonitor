Server lifecycle

Ollama runs a local HTTP server (default port 11434) that has to be up before any pipeline run can call into it. Click below to detect / start it from the UI — no terminal required. After it's up, pull the model you want with ollama pull <model> in a terminal (model downloads are 1–5 GB and not yet automated through this UI).

Install downloads the official installer for your OS (Windows: OllamaSetup.exe, silent install to %LOCALAPPDATA%; macOS / Linux: install.sh piped into sh). Idempotent — does nothing if already installed. Then Detect / start spawns ollama serve as a detached process. Equivalent CLI: python scripts/install_ollama.py.
